# Замер скорости скачивания

Консольный скрипт на Node.js. Принимает URL, десять раз скачивает его по очереди и печатает среднее время запроса, общий объём и скорость.

Зависимостей нет. Следующий запрос начинается только после того, как тело предыдущего ответа прочитано до конца.

## Требования

Node.js 18 или новее (`node -v`).

## Запуск

```bash
node index.js <url>
```

Пример, файл около 5 МБ:

```bash
node index.js "https://speed.cloudflare.com/__down?bytes=5000000"
```

В PowerShell и cmd адрес с `?` или `&` нужно брать в кавычки. Подойдёт любой `http://` или `https://`: картинка, архив, другой файл. На большом файле цифра ближе к пропускной способности канала, потому что задержка соединения меньше влияет на время.

## Пример вывода

Числа ниже условные, это только формат:

```text
Адрес: https://speed.cloudflare.com/__down?bytes=5000000
Запросов: 10, по очереди, каждый до полного тела ответа

[ 1/10] HTTP 200, 410.2 ms, 4.77 MiB
[ 2/10] HTTP 200, 398.0 ms, 4.77 MiB
...
[10/10] HTTP 200, 405.7 ms, 4.77 MiB

Среднее время запроса: 400.0 ms
Общий объём:           47.68 MiB (50000000 байт)
Суммарное время:       4.00 s
Скорость скачивания:   100.00 Mbit/s
```

Если адрес неверный, запрос обрывается или код ответа не 2xx, скрипт останавливается и завершается с ненулевым кодом. Тело ошибочного ответа тоже дочитывается до конца.

## Единицы

| Величина | Единица | Как считается |
| --- | --- | --- |
| Время запроса | миллисекунды (`ms`) | От начала запроса до последнего байта тела. Редиректы входят в это время. |
| Среднее время | миллисекунды (`ms`) | Сумма времён 10 запросов / 10. |
| Объём | байты и `MiB` | Сумма байт тел ответов. Заголовки HTTP не входят. `1 MiB = 1024 × 1024` байт. |
| Суммарное время | секунды (`s`) | Сумма времён 10 запросов. |
| Скорость | мегабиты в секунду (`Mbit/s`) | `(общий объём в байтах × 8) / суммарное время в секундах / 1 000 000`. `1 Mbit/s = 1 000 000` бит/с. |

Заголовок `Accept-Encoding: identity` просит отдать тело без gzip. Объём тогда совпадает с байтами, которые реально пришли по сети, а не с размером после распаковки. `Cache-Control: no-cache` просит не отдавать закэшированную копию. Первый запрос обычно чуть дольше: в него входят DNS и установка соединения.
